安装前 / Before installation

请先结束音频并退出 MicForYou；个人数据不会删除。App 安装到 /Applications。音频驱动需要管理员授权，首次安装后请按提示重启。已有同版或更高版本驱动时跳过该组件。

End audio and quit MicForYou. Personal data is preserved. The app is installed in /Applications. Administrator authorization is required; restart when prompted after driver installation. An existing same/newer driver is skipped.

推荐设备 / Devices

M5 MacBook Air 为已验证基线，已测试 M1 未满足实时要求。其他设备须通过 App 内置检查；建议预留至少 3 GB 磁盘空间。

M5 MacBook Air is the tested baseline. The tested M1 did not meet real-time requirements. Other devices must pass the in-app check. Reserve at least 3 GB disk space.

首次使用 / First use

打开 /Applications/MicForYou.app，选择麦克风、授权录音并注册自己的声音（45 秒）。准备通过后，将输入法的输入设备选为 BlackHole 2ch。

Open /Applications/MicForYou.app, choose and authorize your microphone, and register your voice for 45 seconds. After setup passes, select BlackHole 2ch in the input method.

暂停传送原音，结束才释放麦克风。当前不自动切换系统默认输入。

Pause forwards raw audio; End releases the microphone. System default input is not switched automatically.

本试用版本的 App 为 ad-hoc 签名，组合安装包未 Developer ID 签名或公证。The app is ad-hoc signed; this combined trial installer is not Developer ID signed or notarized.
