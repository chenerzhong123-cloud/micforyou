MicForYou 是一款 Mac 声音过滤工具。它以你注册的声音为参考，减少环境杂音和附近人声的干扰，再把处理后的音频交给豆包输入法识别文字。适合在开放工位、共享办公室等有人交谈的环境中使用。

## 下载安装（试用版本）

**[下载 MicForYou 0.2.2 试用版本（Mac 安装包）](https://github.com/chenerzhong123-cloud/micforyou/releases/download/v0.2.2-trial/MicForYou-0.2.2-trial-macos-arm64.pkg)** · [版本说明与校验文件](https://github.com/chenerzhong123-cloud/micforyou/releases/tag/v0.2.2-trial)

安装包约 443 MB，已包含 App、模型和音频组件。下载安装后，打开 MicForYou，选择麦克风并注册 45 秒声音，再在豆包输入法中选择 **BlackHole 2ch** 即可开始使用。首次安装音频组件后，按提示重启 Mac。

试用版本首次打开可能被 macOS 拦截，处理方法见[安装指南](docs/INSTALL.md)。

## 45 秒声音注册：朗读范文

使用日常麦克风，在安静环境以平时说话的音量和语速朗读，自然停顿。点击“注册我的声音”后，等 3 秒倒计时结束再开口。下面的文本可供参考，也可以读自己的普通文本；**如果提前读完，就从头继续，直到 45 秒录音结束**，不必赶着读完或刻意改变声音。

> 今天早上，我打开窗户，看见阳光落在桌面上。窗外的树叶轻轻晃动，远处传来几声鸟叫。我给自己倒了一杯温水，准备开始今天的工作。
>
> 上午先整理昨天的笔记，再把需要讨论的问题写下来。下午三点有一场会议，我会提前检查麦克风，确认声音清楚，也给自己留一点思考的时间。
>
> 忙完以后，我想去附近走一走，买些水果和面包。回家的路上，可以看看街边的小店，也可以给朋友打个电话，聊聊最近读过的书。这些都是平常的小事，我会用自己习惯的声音说清楚。

## 性能要求

- **系统**：macOS 14 或更高，Apple Silicon Mac；不支持 Intel Mac。
- **推荐设备**：MacBook Air M5 是目前唯一完成较长时间验证的基线（音频链路内部延迟 p95 约 260 ms，测量范围不含豆包识别耗时）。已测试的一台 M1 MacBook Pro 未达到实时门槛，不支持实时过滤。
- **其他设备**：M5 的结果不能外推到其他机型；任何设备都须通过 App 注册时的内置性能检查。建议接通电源使用。
- **空间**：至少预留 3 GB。App 安装后约 1 GB，声音注册还会生成个人模型。

## 关键限制

- 过滤可减少干扰，**不能保证完全隔离旁人的声音**；本人不说话时，旁人的声音仍可能进入识别。
- **暂停 ≠ 关闭麦克风**：暂停时原始声音（含旁人和环境声）继续送往输入法；点击“结束”才释放麦克风。退出界面也会保留后台音频。
- MicForYou 的过滤和注册在本机完成、数据保存在本机；豆包的语音识别遵循其自身的规则，本机处理不代表整个输入流程离线。

更多限制与故障排查见[使用指南](docs/USAGE.md)。
