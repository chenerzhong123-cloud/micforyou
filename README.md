MicForYou 是一款 Mac 声音过滤工具。它以你注册的声音为参考，减少环境杂音和附近人声的干扰，再交给豆包输入法识别文字。适合在开放工位、共享办公室等有人交谈的环境中使用。

## 如何安装

目前是测试版，仅向有仓库访问权限的用户提供下载。

1. 从 [下载页面](https://github.com/chenerzhong123-cloud/micforyou/releases) 下载 `.pkg` 安装包（约 443 MB）。App、模型和音频组件都已包含，无需另装开发工具。
2. 双击安装，按提示输入管理员密码；若要求重启，请先重启 Mac。使用旧版时，先点击“结束”并退出，再安装。
3. 打开“应用程序”中的 MicForYou，在“设置”里选择麦克风、允许录音，并在安静环境朗读 45 秒，注册自己的声音。等待 App 完成准备和性能检查。
4. 在豆包输入法中将输入设备选为 **BlackHole 2ch**，然后点击 MicForYou 的“开始过滤”，等到就绪即可语音输入。

测试安装包尚未完成 Apple 签名与公证。若系统阻止打开，请参阅 [详细安装指南](docs/BUNDLED_APP.md)。

## 性能要求

- **系统**：macOS 14 或更高，Apple Silicon Mac；不支持 Intel Mac。
- **推荐设备**：MacBook Air M5，是目前已验证的基线。已测试的 M1 未达到实时要求，不推荐使用。
- **其他设备**：须通过 App 内置性能检查，不能仅凭芯片型号保证效果；建议接通电源。
- **空间**：至少预留 3 GB。App 安装后约 1 GB，声音注册还会生成个人模型。

## 补充说明

- **暂停不等于关闭麦克风**：暂停时原始声音继续送往输入法；点击“结束”才释放麦克风。退出界面也会保留后台音频。
- **数据与效果**：MicForYou 在本机处理声音、保存声音注册；豆包的识别遵循其自身规则。过滤可减少干扰，但不能保证完全隔离旁人的声音。
