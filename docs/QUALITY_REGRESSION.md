## 目的

## 新候选的通过规则

1. Q01 的本人句首、主要语义和句尾不得相对当前版本明显退化。
2. Q02 的可辨认他人语句必须显著少于当前版本，不能只靠整体降音量。
3. Q03 中本人内容应保留、他人内容应减少；两项分别判断。
4. 新增 overlap 样本后，目标低于他人时仍需单独报告。
5. 通过离线审听后，再运行同一 ONNX correctness、p95 ≤ 500 ms、30 分钟和断链恢复门。

人工审听使用“更好 / 相同 / 更差”以及“本人是否完整 / 他人是否减少”四个短答案即可，不要求人工计时或逐字转写。
