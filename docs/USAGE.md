# 使用 MicForYou

[English](USAGE.en.md) · [返回 README](../README.md)

本文说明菜单栏界面的真实行为、性能要求、数据存放位置、故障排查和已知限制。安装与首次注册见[安装指南](INSTALL.md)。

## 日常流程

首次设置完成后，打开 MicForYou 菜单，点击“开始过滤”，等状态显示“正在过滤”，再用豆包语音输入。

菜单栏始终显示：当前状态（如“可以开始”“正在过滤”“正在恢复”“已安全静音”）、当前链路（`实体麦克风 → BlackHole 2ch`）、当前推荐操作，以及设置入口。`试用` 标签常驻可见。

## 各操作的真实行为

| 操作 | 送往输入法的声音 | 麦克风 |
| --- | --- | --- |
| 开始过滤 | 处理后的音频；模型加载完成前静音 | 使用中 |
| 暂停过滤 | **原始声音继续输入，包括本人、旁人和环境声** | 仍在使用 |
| 继续过滤 | 重建流式状态后恢复过滤，不重开设备 | 仍在使用 |
| 结束 | 停止本链路的声音输出 | 释放 |
| 退出界面 | 后台音频继续，保持当前模式 | 运行或暂停时仍在使用 |

**暂停的是过滤，不是收音。** 要关闭麦克风，请点击“结束”，再退出界面。更换麦克风或重新注册前也必须先“结束”；过滤运行期间，设置中的麦克风选择和注册操作会被锁定。暂停与继续不需要重新选择豆包输入设备。

MicForYou 不自动修改系统默认输入。如果豆包没有独立输入设备选择器，可手动在“系统设置 → 声音 → 输入”选择 BlackHole 2ch；结束后按需改回实体麦克风。系统输出继续使用原来的扬声器／耳机。

偏好 Terminal 的源码用户也可以使用：

```bash
uv run micforyou status
uv run micforyou start
uv run micforyou pause   # 原音直通；麦克风继续工作
uv run micforyou resume  # 恢复过滤
uv run micforyou stop    # 结束并释放麦克风
```

## 性能要求

- **系统**：macOS 14 或更高，Apple Silicon；不支持 Intel Mac。
- **推荐设备**：MacBook Air M5 是目前唯一完成较长时间验证的基线，音频链路内部延迟 p95 约 260 ms。该数字只覆盖 MicForYou 内部音频路径，不含 CoreAudio 采集缓冲、BlackHole 到输入法的传递和豆包识别耗时，不能当作完整语音输入的延迟承诺。
- 已测试的一台 M1 MacBook Pro 最佳有效 RTF 为 1.052，低于实时要求，不支持实时过滤。
- 其他设备不能仅凭芯片型号推定支持；负载和电源状态会让同一台机器在达标与不达标之间波动（内置检查在注册时测量）。
- 建议接通电源使用；性能不达标时重新注册重试。

## 数据存放位置

个人录音、个性化模型、配置和运行报告保存在 `~/Library/Application Support/MicForYou/`，不上传云端：

- `config.json` — 当前配置（设备、模型路径、性能参数）；
- `registrations/` — 声音注册的录音与个人模型；成功的旧注册保留用于回退，可能占用额外空间；失败的候选注册会被清理；
- `work/runs/` — 运行报告；日志不保存音频、embedding 或输入法文字。

MicForYou 的声音前处理与注册在本机进行；它不实现语音识别，也不输出文字。豆包的识别和数据处理遵循豆包自身规则——不能把“本机前处理”理解为整个语音输入流程离线。

## 故障排查

- **“需要完成设置”**：在“设置”中检查驱动、麦克风和声音注册进度；源码用户也可运行 `uv run micforyou status`。
- **注册时提示录音问题**（声音太轻、失真或有效讲话不足）：按提示调整——离麦克风距离合适、不要压低声音、自然连续朗读约 15 秒后重录；检查失败不会影响已保存的旧注册。
- **“没有文字”**：确认状态已就绪、豆包选中 `BlackHole 2ch`，并检查 macOS 对实际录音进程的麦克风授权。
- **“麦克风还在使用”**：暂停和退出界面都会保留音频，请先“结束”；也可运行 `uv run micforyou stop`。
- **所选麦克风断开**：显示“正在恢复”，恢复前保持静音，不会自动改用其他麦克风；不可恢复的故障显示“已安全静音”并提供重试。
- **默认运行中故障**：静音（隐私优先）；主动暂停则是明确的原音直通。两种状态有区分，不会把故障悄悄当作暂停。

## 已知限制

- 过滤可减少部分他人声音，**不能保证完全隔离**；本人不说话时，其他人的声音仍可能被识别。它不是身份验证或隐私隔离工具。
- 新设备首次安装、真实麦克风／豆包 30 分钟混合运行等真机验收尚未完成；暂停直通行为已通过软件检查与真实 ONNX 合成输入验证，不代表真机验收已通过。
- App 界面当前为中文；组合安装包未做 Developer ID 签名／公证。
