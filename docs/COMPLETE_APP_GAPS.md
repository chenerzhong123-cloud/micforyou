## 实现取舍

保留现有 Python / ONNX 流式链路，免安装 Python 无需全 Swift 重写。
精简推理子集避免加载无用的训练、ASR 和 VAD 模块；神经模块和通用 checkpoint 保持原样。App 约 1 GB，个人注册会增加模型和报告占用。

一体安装器完成 App 与音频驱动安装；管理员授权／可能重启、声音注册、macOS 麦克风权限和输入法设备选择仍是首次设置的必要步骤。近期目标是“下载完整 App 后按引导设置，以后点击即可用”。

M5 MacBook Air 是已验证基线，已测试 M1 未达到当前模型实时要求。打包不会改变硬件性能；其他 Mac 应通过本地性能检查。支持 M1 需要独立进行模型优化 / 更换和质量验收。

## 剩余发布步骤

1. 完成全部实际原生依赖的最终分发复核；已识别的 LGPL／MPL 源码、声明和替换机制随包提供。
2. 在无开发环境的新 Mac 上完成权限、真实录音、个人模型生成和输入法接入。
3. 完成真实麦克风 / 豆包 30 分钟运行、暂停 / 继续 / 结束及升级检查。
4. 配置 Developer ID / 公证，或明确保留极客 Alpha 的 ad-hoc 安装方式。
5. 确定公开访问方式后上传完整资产与 checksum，更新双语 README 的真实下载状态。
