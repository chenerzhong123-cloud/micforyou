# MicForYou 应用体验

目标：让日常使用只需要一次点击，同时把设备选择、声音注册和实验版边界放在一个明确的设置页中。应用不实现 ASR，不修改系统默认输入；豆包继续负责把 BlackHole 的声音转成文字。

## 界面结构

### 菜单栏

菜单栏是日常入口，只展示四类信息：

1. 当前状态，例如“可以开始”“正在过滤”“正在恢复”“已安全静音”；
2. 当前链路：`实体麦克风 → BlackHole 2ch`；
3. 当前唯一推荐动作，例如“开始过滤”“暂停”或“继续过滤”；
4. 设置、日志和退出界面的次要入口。

`Alpha` 标签始终可见。质量边界的完整说明放在设置中，危险状态则直接在菜单内显示，不依赖用户打开日志。

### 设置

设置页只负责低频操作：

- 选择实体麦克风并应用；
- 确认输出固定为 `BlackHole 2ch`；
- 更换常用麦克风或识别明显变差时重新注册声音；
- 查看 Experimental Alpha 的效果边界和故障静音策略。

过滤运行期间，麦克风切换和重新注册会被锁定，避免中途改变音频链路。

## 首次准备

1. 打开菜单栏的 **MicForYou → 设置**。
2. 在“实体麦克风”中选择实际收音设备，点击“应用”。
3. 若尚未注册当前用户声音，点击“重新注册”，按提示自然朗读约 45 秒。
4. 打开豆包输入法，把它的输入设备选择为 `BlackHole 2ch`。
5. 返回 MicForYou，看到“可以开始”后点击“开始过滤”。

MicForYou 不会自动切换豆包或 macOS 的默认麦克风，因为静默切换可能把未过滤声音送入错误链路。

## 日常流程

```text
需要设置 ──设置完成──> 可以开始 ──点击──> 正在加载 ──成功──> 正在过滤
                                                   │
                                    异常片段 ──────┴──> 正在恢复（静音）──> 正在过滤

正在过滤 ──暂停──> 已暂停 ──继续──> 正在加载
                         └─结束──> 可以开始

不可恢复故障 ──> 已安全静音 ──检查设备并重试──> 正在加载
```

暂停会释放实体麦克风；继续时重新建立完整过滤状态。退出界面不会停止已经运行的后台过滤。

## 验收清单

1. 未连接已配置麦克风时，菜单显示“需要完成设置”，不能开始过滤。
2. 连接并应用麦克风后，菜单显示“可以开始”。
3. 点击“开始过滤”后，状态依次进入“正在加载”和“正在过滤”。
4. 运行中可暂停；暂停后既可继续，也可直接结束。
5. 拔出或短暂中断麦克风时，显示“正在恢复”，恢复前保持静音，而不是让整条链路永久失声。
6. 不可恢复故障显示“已安全静音”，并提供“重新尝试”。
7. 过滤运行期间，设置中的设备选择和声音注册不可操作。
8. 豆包选择 `BlackHole 2ch` 后，最终文字仍由豆包输出；MicForYou 不显示或保存转写内容。

## 当前质量边界

当前模型与权重保持冻结。已知效果是“本人声音较完整、他人声音有所减少”，不是严格的身份隔离；目标用户缺席时仍可能放行他人声。因此界面使用 `Experimental Alpha`，且默认采用隐私优先的故障静音策略。
